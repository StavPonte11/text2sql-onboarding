# Project Description and Mission

## The Agency — TextToSQL Studio

TextToSQL Studio is a production-grade, self-service platform designed to bridge the gap between natural language and structured data querying. It empowers both data owners and business users by providing a robust interface to manage the lifecycle of database tables used in TextToSQL applications.

### Mission

Our mission is to enable accurate, safe, and governed natural language querying over enterprise data. We achieve this by:

1. **Empowering Data Owners**: Providing self-service tools to enrich database schemas with semantic business context (descriptions, synonyms, value enums).
2. **Ensuring Reliability**: Enforcing strict regression testing via "Golden Question" evaluation suites before exposing data to AI models.
3. **Guaranteeing Security & Compliance**: Auditing all AI-generated queries and ensuring proper data access governance.

### Core Value Proposition

Instead of feeding raw, unannotated database schemas directly into Large Language Models (which frequently results in hallucinations and wrong SQL joins), TextToSQL Studio introduces a structured governance layer. Data is curated, tested, and systematically optimized *before* being queried by the AI Agent.
